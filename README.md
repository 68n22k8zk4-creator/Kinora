# KINORA 💜

Все твои сайты с фильмами, сериалами, мультфильмами и аниме в одном приложении.
Добавляешь адрес сайта, KINORA сама находит на нём тайтлы (постер + название + ссылка) и строку поиска,
и показывает всё в едином каталоге, поиске и «продолжить просмотр».
SwiftUI, iOS 16+, только iPhone. Все данные хранятся на устройстве, без серверов.

## Сборка (GitHub → Codemagic → GBox)

1. Распакуй архив и залей содержимое папки `KINORA` в корень нового репозитория на GitHub
   (в корне должны лежать `project.yml`, `codemagic.yaml` и папка `KINORA/`).
2. В Codemagic подключи репозиторий: Codemagic сам найдёт `codemagic.yaml`, workflow называется **KINORA – unsigned IPA**.
3. Запусти сборку. Скрипт ставит XcodeGen, генерирует `KINORA.xcodeproj`, собирает без подписи
   и упаковывает `output/KINORA-unsigned.ipa`. Её ты найдёшь в разделе Artifacts.
4. Скачай IPA, подпиши в GBox своим `.p12` и `.mobileprovision` и установи.

Bundle ID: `com.kinora.app`. При необходимости поменяй его в `project.yml` (`PRODUCT_BUNDLE_IDENTIFIER`).
Xcode-проект в репозиторий класть не нужно, он генерируется из `project.yml`.

## Как работает «точная секунда»

* **Прямая ссылка (mp4/m3u8) или скачанный файл**: встроенный плеер на AVPlayer сохраняет позицию каждые 5 секунд, а также при паузе, закрытии и сворачивании.
* **Сайт-источник**: открывается во встроенном браузере. Скрипт находит HTML5-видео (в том числе внутри iframe), каждые 3 секунды пишет позицию и при следующем открытии перематывает на неё. Если на странице найдена прямая ссылка на видео, в меню появится «Открыть в плеере KINORA».
* DRM не обходится. Скачивание работает только для прямых ссылок на файлы.

## Онлайн-каталог (по желанию)

Настройки → TMDB → вставь бесплатный ключ с themoviedb.org. После этого «Умный поиск» находит любые тайтлы с постерами, сезонами и названиями серий.

## Весь сайт, а не только главная

У каждого сайта есть вкладка **«Весь сайт»**:
1. **Карта сайта** (`sitemap.xml`): служебный список всех страниц для поисковиков, обычно там все тайтлы. Читается за секунды.
2. **Глубокий скан**: если карты нет, KINORA сама проходит разделы сайта и листает все страницы (до 250 страниц), нажимая «Показать ещё».
Названия и постеры записей из карты сайта подтягиваются со страниц по мере прокрутки. Поиск ищет и по полному списку.

## Как KINORA читает сайты

`Services/SiteScraper.swift` открывает страницу в невидимом браузере (с JavaScript и куками),
находит карточки «ссылка + картинка + название» и форму поиска. Отдельный парсер под каждый сайт не нужен.
Если сайт закрыт проверкой «я не робот», откройте его один раз кнопкой 🌐: куки общие, и следующее сканирование пройдёт.
Если поиск не нашёлся сам, впишите шаблон с `{query}` в настройках источника.

Первый запуск пустой: никаких демо-тайтлов, истории и «продолжить просмотр».
